## Примечания

### Важно!

1. **Дисклеймер обязателен** - данные о микронутриентах являются приближенными
2. **Производительность** - графики генерируются на лету, может занять 3-5 секунд
3. **Хранение** - temporary файлы удаляются автоматически после отправки PDF
4. **Формат** - микронутриенты хранятся в JSON для гибкости
