# План реализации расширенного функционала NutriAI

## Анализ требований

### 🎯 Группа 1: Улучшение процесса создания рациона (Сложность: Средняя)

**1. Уточнение предпочтений перед созданием**
- Добавить шаги в ConversationHandler для meal_plan
- Спрашивать: особые пожелания, нелюбимые продукты, предпочитаемые блюда
- Обновить prompt для AI с учетом этих данных
- **Оценка:** 2-3 часа

**2. Обратная связь после создания**
- Добавить состояние "ожидание обратной связи"
- Кнопки: "Всё устраивает" / "Хочу изменить"
- При изменении - собрать пожелания и пересоздать рацион
- **Оценка:** 2 часа

**3. Переиспользование недельного рациона для дневного**
- При создании дневного плана проверять наличие недельного
- Брать соответствующий день из недельного плана
- Копировать приемы пищи и продукты
- **Оценка:** 1-2 часа

### ⏰ Группа 2: Жизненный цикл рациона (Сложность: Низкая)

**4. Автоматическое удаление по срокам**
- Создать background task (APScheduler)
- Проверять expired планы каждый час
- Деактивировать планы по end_date
- **Оценка:** 2 часа

### 🔔 Группа 3: Напоминания и коррекция (Сложность: Высокая)

**5. Напоминания о приемах пищи**
- Создать таблицу meal_reminders (время, прием пищи)
- Background task для отправки напоминаний
- Настройки включения/выключения напоминаний
- **Оценка:** 4-5 часов

**6. Коррекция рациона при добавлении другой еды**
- При добавлении еды проверять активный план
- Анализировать отклонение от плана
- Генерировать скорректированный план на оставшийся день через AI
- Обновлять planned_meals
- **Оценка:** 5-6 часов

### 🧠 Группа 4: Психологический подход (Сложность: Средняя)

**7. Предупреждения при выходе за пределы**
- Проверять daily totals vs targets
- Если превышение >20% - показывать предупреждение
- Объяснять последствия
- **Оценка:** 2 часа

**8. Дружелюбный тон**
- Создать базу фраз (phrases.py)
- Использовать ободряющие формулировки
- Добавить в AI prompt инструкции по тону общения
- **Оценка:** 1-2 часа

**9. Психотерапевтический подход при нарушениях**
- При серьезном нарушении (>30% отклонение) запускать диалог
- AI анализирует причины (стресс, привычка, доступность)
- Предлагать альтернативы и стратегии
- Сохранять insights в таблицу user_behavior_insights
- **Оценка:** 4-5 часов

### 💬 Группа 5: Мониторинг самочувствия (Сложность: Высокая)

**10. Опросы после еды**
- Создать таблицу meal_feedback (meal_id, time_after, rating, symptoms)
- После добавления еды - schedule опрос через 30-60 мин
- Анализировать паттерны через AI (food_intolerances)
- Обновлять dislikes/allergies при обнаружении паттернов
- **Оценка:** 6-8 часов

### 🔬 Группа 6: Расширенная нутрициология (Сложность: Очень высокая)

**11. Учет микроэлементов и витаминов**
- Расширить модель PlannedMeal (добавить поля для витаминов/минералов)
- Обновить AI prompt для расчета микронутриентов
- Создать таблицу daily_micronutrients
- Показывать в PDF и статистике
- **Оценка:** 8-10 часов

**12. Анализ медицинских анализов**
- Создать таблицу medical_tests (user_id, test_type, upload_date, file_path, analysis_result)
- Добавить шаг в онбординг для загрузки анализов (опционально)
- Использовать Claude Vision для анализа фото/PDF анализов
- Извлекать ключевые показатели (гемоглобин, ферритин, B12, витамин D и т.д.)
- Обновлять AI prompt для рациона с учетом дефицитов
- **Оценка:** 12-15 часов

### ⚖️ Группа 7: Юридические требования (Сложность: Низкая)

**13. Дисклеймер**
- Добавить показ дисклеймера при первом запуске
- Требовать согласие (Accept/Decline)
- Сохранять факт согласия в БД
- Показывать в начале PDF отчетов
- **Оценка:** 2 часа

**14. Не ставить диагнозы**
- Обновить system prompts для AI
- Использовать формулировки типа "обнаружены признаки", "рекомендуем консультацию"
- Добавить автоматическую проверку ответов AI на запрещенные формулировки
- **Оценка:** 1-2 часа

## Технические требования

### Новые модели БД:
1. `meal_reminders` - настройки напоминаний
2. `meal_feedback` - обратная связь о самочувствии
3. `user_behavior_insights` - психологические инсайты
4. `daily_micronutrients` - учет микронутриентов
5. `medical_tests` - загруженные анализы
6. `user_consent` - согласие с дисклеймером

### Новые сервисы:
1. `ReminderService` - управление напоминаниями
2. `MealCorrectionService` - коррекция рациона
3. `FeedbackAnalysisService` - анализ паттернов самочувствия
4. `MedicalTestAnalysisService` - анализ анализов
5. `SchedulerService` - фоновые задачи

### Новые dependencies:
1. `APScheduler` - для фоновых задач и напоминаний
2. `pdf2image` / `PyMuPDF` - для анализа PDF анализов
3. Расширенное использование Claude Vision API
