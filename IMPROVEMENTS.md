# Доработки бота NutriAI

## 1. Отложенное уточнение в функции "Ресторан"

### Описание
После получения рекомендаций из ресторана, бот через 5 минут автоматически спрашивает пользователя, воспользовался ли он рекомендациями, и если да - добавляет выбранное блюдо в дневник питания.

### Workflow
1. **Пользователь получает рекомендации** (2-3 блюда с КБЖУ)
2. **Через 5 минут** бот отправляет сообщение: "Воспользовался ли ты моими рекомендациями?"
3. **Два варианта ответа:**
   - ✅ **Да, воспользовался** → показывает список рекомендаций с кнопками
   - ❌ **Нет, выбрал другое** → дружелюбное завершение

4. **При выборе "Да":**
   - Показывает пронумерованный список всех рекомендаций
   - Каждая с кратким названием и полными КБЖУ
   - Пользователь нажимает кнопку с номером (1, 2, или 3)

5. **Автоматическое добавление в дневник:**
   - Блюдо добавляется в соответствующий прием пищи
   - Показывается обновленный прогресс по дню
   - Учитываются калории и макросы

### Технические детали
- **Формат рекомендаций**: Claude возвращает JSON с структурированными данными
- **Хранение**: Рекомендации сохраняются в `context.user_data`
- **Отложенное сообщение**: `job_queue.run_once(restaurant_followup_callback, when=300)`
- **Новые handlers**:
  ```python
  restaurant_followup_callback()         # Отправка уточнения
  handle_restaurant_used_response()      # Обработка ответа
  handle_restaurant_dish_selection()     # Добавление в дневник
  ```

### Файлы
- `app/bot/handlers/restaurant.py` - основная логика (+240 строк)
- `app/bot/main.py` - регистрация callback handlers
- `app/services/claude_ai.py` - изменен формат ответа на JSON

## 2. Детекция неподходящего контента при анализе фото

### Описание
Бот теперь проверяет фотографии на наличие неподходящего контента (несъедобные предметы, неэтичный материал) перед анализом еды и реагирует соответствующим образом.

### Что проверяется
- ❌ **Несъедобные предметы**: фекалии, мусор, отходы
- ❌ **Неэтичный контент**: изображения насилия, трупов
- ❌ **Нерелевантный контент**: что-то явно не связанное с едой

### Реакция бота
При обнаружении неподходящего контента:

```
⚠️ Обнаружен неподходящий контент

Причина: [причина от AI]

⛔️ Это не смешно и не корректно.

Я создан, чтобы помогать с питанием и здоровьем.
Если у тебя есть проблемы, с которыми нужна помощь,
пожалуйста, обратись к специалисту:

🆘 Экстренная психологическая помощь:
• Телефон доверия: 8-800-2000-122 (бесплатно, круглосуточно)
• Служба поддержки: 8-495-989-50-50

💚 Береги себя. Если что-то беспокоит - обратись за помощью к профессионалам.
```

### Технические детали

#### Обновленный prompt для Claude:
```
ПЕРВАЯ ПРОВЕРКА - Безопасность контента:
Перед анализом еды проверь, содержит ли изображение:
- Несъедобные предметы (фекалии, мусор, отходы и т.д.)
- Неэтичный или шокирующий контент (труп, насилие и т.д.)
- Любой контент, явно не связанный с едой...
```

#### JSON структура ответа:
**При неподходящем контенте:**
```json
{
  "inappropriate_content": true,
  "reason": "обнаружены несъедобные предметы"
}
```

**При нормальном контенте:**
```json
{
  "inappropriate_content": false,
  "dishes": [...],
  "total_nutrition": {...}
}
```

#### Обработка в коде:
```python
if result and result.get("inappropriate_content", False):
    reason = result.get("reason", "неподходящий контент")
    # Показываем предупреждение
    # Логируем: logger.warning(f"Inappropriate content: {reason}")
    return ConversationHandler.END
```

### Файлы
- `app/services/claude_ai.py` - обновлен prompt для анализа фото
- `app/bot/handlers/photo.py` - добавлена проверка и обработка флага

### Логирование
- Все случаи неподходящего контента логируются с WARNING уровнем
- Формат: `"Inappropriate content detected for user {user_id}: {reason}"`
- Позволяет отслеживать попытки злоупотребления
