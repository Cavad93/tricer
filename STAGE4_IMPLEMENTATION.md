### 2. Модель MedicalAnalysis

Новая модель для хранения медицинских анализов:

```sql
CREATE TABLE medical_analyses (
    id INTEGER PRIMARY KEY,
    user_id INTEGER NOT NULL,
    analysis_type VARCHAR(100),  -- Тип анализа (ОАК, биохимия и т.д.)
    analysis_date DATETIME,      -- Дата сдачи анализа
    raw_data JSON,                -- Сырые данные (все показатели)
    file_url VARCHAR(500),        -- URL файла с анализами
    ai_analysis JSON,             -- Результат анализа от Claude AI
    detected_deficiencies JSON,   -- Выявленные дефициты
    needs_doctor_consultation BOOLEAN,  -- Флаг: нужен врач
    recommendations TEXT,         -- Рекомендации по питанию
    user_notes TEXT,              -- Заметки пользователя
    created_at DATETIME,
    updated_at DATETIME
);
```

**Поля:**
- `raw_data` - все показатели из анализа (гемоглобин, ферритин, витамин D и т.д.)
- `ai_analysis` - полный анализ от Claude
- `detected_deficiencies` - список выявленных дефицитов с объяснением
- `needs_doctor_consultation` - флаг необходимости консультации врача

---

### 3. Сервис MedicalAnalysisService

Файл: `app/services/medical_analysis_service.py`

#### Основные методы:

**1. `analyze_lab_results(user, raw_data, ...)`**
- Анализирует лабораторные показатели с помощью Claude AI
- Выявляет дефициты микро- и макронутриентов
- НЕ ставит диагнозы и НЕ дает рекомендации по лечению
- Рекомендует врача при существенных отклонениях

**Пример использования:**
```python
result = await MedicalAnalysisService.analyze_lab_results(
    user=user,
    raw_data={
        "hemoglobin": {"value": 110, "unit": "г/л", "normal": "120-160"},
        "ferritin": {"value": 15, "unit": "мкг/л", "normal": "30-300"},
        "vitamin_d": {"value": 18, "unit": "нг/мл", "normal": "30-100"}
    },
    analysis_type="Биохимический анализ крови",
    analysis_date=datetime.now()
)

# result содержит:
# - detected_deficiencies: [{"nutrient": "Железо", "severity": "moderate", ...}]
# - needs_doctor_consultation: True/False
# - recommendations: ["Увеличить продукты с железом", ...]
# - summary: "Краткая сводка"
```

**2. `save_analysis(db, user_id, raw_data, ai_analysis, ...)`**
- Сохраняет результаты анализа в БД

**3. `get_latest_deficiencies(db, user_id)`**
- Получает актуальные дефициты из последнего анализа
- Используется для формирования рациона

**4. `generate_medical_restrictions(user, db)`**
- Генерирует ограничения по питанию на основе:
  - Хронических заболеваний
  - Удаленных органов
  - Последних медицинских анализов
- Использует Claude AI
- Сохраняет результат в `user.medical_restrictions`

**Пример ограничений:**
```json
{
  "foods_to_increase": ["рыба (омега-3)", "красное мясо (железо)", "орехи (магний)"],
  "foods_to_limit": ["соль (не более 5г/день)", "простые углеводы"],
  "foods_to_avoid": ["алкоголь", "жирное жареное"],
  "nutrients_to_focus": ["железо", "витамин D", "магний"],
  "general_notes": ["Дробное питание 5-6 раз в день"],
  "restrictions_summary": "Ограничение соли и жиров, акцент на железо и витамин D"
}
```

### 4. Расширение ClaudeAIService

Добавлены новые методы в `app/services/claude_ai.py`:

Добавлены новые состояния в `OnboardingStates`:

## Интеграция с meal planning

### Обновление `meal_plan_service.py`

При формировании рациона AI учитывает:

1. **Хронические заболевания** из `user.chronic_conditions`
2. **Удаленные органы** из `user.removed_organs`
3. **Медицинские ограничения** из `user.medical_restrictions`
4. **Выявленные дефициты** из последнего медицинского анализа

**Пример промпта для AI:**
```
🏥 МЕДИЦИНСКИЕ ОГРАНИЧЕНИЯ:
Хронические заболевания: диабет 2 типа, гипертония
Удаленные органы: желчный пузырь

Ограничения по питанию:
- ИЗБЕГАТЬ: жирное, жареное, алкоголь
- ОГРАНИЧИТЬ: соль (до 5г/день), сахар, простые углеводы
- УВЕЛИЧИТЬ: клетчатка, овощи, рыба
- ФОКУС на нутриентах: магний, калий, омега-3

Выявленные дефициты (из анализов):
- Железо (умеренный дефицит) - гемоглобин 110 г/л
- Витамин D (дефицит) - 18 нг/мл

ВАЖНО: Учти все ограничения при составлении рациона!
```

## Безопасность и этика

### Принципы работы AI:

1. **НЕ ставит диагнозы**
   - ❌ "У вас анемия"
   - ✅ "Пониженный гемоглобин может указывать на дефицит железа"

2. **НЕ дает медицинские рекомендации**
   - ❌ "Принимайте препараты железа"
   - ✅ "Увеличьте продукты, богатые железом: красное мясо, печень, бобовые"

3. **Рекомендует врача при отклонениях**
   - Если показатели существенно выходят за норму
   - Если обнаружено несколько критических дефицитов
   - Устанавливает флаг `needs_doctor_consultation = True`

4. **Формулировки**
   - "Могут быть признаки..."
   - "Возможен дефицит..."
   - "Рекомендую проконсультироваться с врачом"
