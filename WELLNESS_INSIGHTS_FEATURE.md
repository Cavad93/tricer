# Интересные Факты - Система Анализа Корреляций

## Описание

Новая функция "Интересные факты" автоматически анализирует данные пользователя о питании и самочувствии, находит устойчивые корреляции и предоставляет научно обоснованные инсайты.

## Основные Компоненты

### 1. Модель InsightFact (`app/models/insight_fact.py`)

Хранит найденные корреляции между продуктами и самочувствием:

- **Информация о продукте**: название, категория
- **Метрика самочувствия**: энергия, настроение, пищеварение, ясность ума, сон, стресс
- **Статистика**: коэффициент корреляции, уровень достоверности (95%+), количество наблюдений
- **Научное объяснение**: найдено AI с помощью веб-поиска
- **Направление влияния**: положительное/отрицательное

### 2. CorrelationAnalysisService (`app/services/correlation_analysis_service.py`)

Основной сервис для анализа корреляций:

**Ключевые функции:**

- `analyze_user_correlations()` - анализирует данные пользователя за период (90 дней по умолчанию)
- `_build_food_wellness_pairs()` - строит пары "продукт-самочувствие"
- `_analyze_food_metric_correlation()` - проводит статистический анализ (t-test, Cohen's d)
- `_get_scientific_explanation()` - получает научное объяснение через AI и веб-поиск

**Требования для создания факта:**
- Минимум 10 наблюдений употребления продукта
- Уровень достоверности 95%+
- Коэффициент корреляции >= 0.6
- Средний эффект >= 0.5 баллов

**Статистические методы:**
- t-test для проверки значимости различия
- Cohen's d для оценки размера эффекта
- Сравнение с общим средним пользователя

### 3. FoodWarningService (`app/services/food_warning_service.py`)

Сервис для предупреждений при добавлении еды:

- `get_food_warnings()` - проверяет продукты против персональных фактов
- `format_warnings_for_user()` - форматирует предупреждения для показа

### 4. Интерфейс в Отчётах (`app/bot/handlers/reports.py`)

Добавлена кнопка **"💡 Интересные факты"** в раздел Отчёты:

- `wellness_insights_callback()` - обработчик кнопки
- Автоматически запускает анализ если фактов нет
- Показывает все найденные корреляции с научными объяснениями
- Разбивает длинные сообщения на части (лимит Telegram 4096 символов)

## Интеграция с Существующими Функциями

### AI Чат (`app/services/chat_service.py`)

Факты автоматически передаются в контекст AI чата:

```python
context["personal_insights"] = [
    "Яблоко положительно влияет на энергию (достоверность 96%) - Высокое содержание железа...",
    "Кофе негативно влияет на сон (достоверность 98%) - Кофеин блокирует аденозин..."
]
```

AI использует эти факты для персонализированных советов.

### Составление Рациона

Факты могут быть учтены при генерации плана питания (интеграция планируется).

### Добавление Еды

При добавлении продуктов бот может показывать предупреждения на основе фактов (интеграция с FoodWarningService).

## Как Это Работает - Пример

1. **Сбор данных** (автоматически):
   - Пользователь добавляет "Яблоко" 15 раз за 2 месяца
   - После каждого приёма заполняет wellness опрос

2. **Анализ** (фоново):
   - Система находит, что после яблок уровень энергии в среднем +1.2 балла выше обычного
   - p-value = 0.02 → уверенность 98%
   - Корреляция статистически значима

3. **Научное объяснение** (через AI):
   - Веб-поиск: "яблоко влияние на уровень энергии здоровье"
   - AI анализирует источники и генерирует объяснение:
     *"Яблоки содержат натуральные сахара и железо, которые улучшают оксигенацию крови и повышают энергию"*

4. **Сохранение факта**:
   - InsightFact создаётся в БД
   - is_verified = True, confidence = 0.98

5. **Использование**:
   - Пользователь видит в разделе "Интересные факты"
   - AI чат знает об этом и даёт персональные советы
   - При добавлении яблока показывается: "✅ Яблоко положительно влияет на вашу энергию"

## Использование

### Для Пользователя

1. Регулярно добавляйте приёмы пищи (📸 Добавить еду)
2. Заполняйте опросы о самочувствии (приходят автоматически через 30 минут)
3. Через 2-3 недели нажмите **Отчёты → 💡 Интересные факты**
4. Изучите найденные корреляции с научными объяснениями

### Для Разработчика

**Запустить анализ вручную:**

```python
from app.services.correlation_analysis_service import CorrelationAnalysisService

service = CorrelationAnalysisService()
insights = await service.analyze_user_correlations(
    session=db_session,
    user_id=1,
    days_back=90
)
```

**Получить предупреждения для еды:**

```python
from app.services.food_warning_service import FoodWarningService

warnings = await FoodWarningService.get_food_warnings(
    session=db_session,
    user_id=1,
    food_names=["Яблоко", "Кофе"]
)
```

**Получить факты пользователя:**

```python
insights = await service.get_user_insights(
    session=db_session,
    user_id=1,
    active_only=True
)
```

## Фоновый Анализ (Планируется)

Планируется добавить фоновую задачу (Celery/APScheduler):

- Запуск: раз в сутки
- Анализирует всех активных пользователей
- Создаёт новые факты при обнаружении корреляций
- Деактивирует старые факты если паттерн изменился

## Настройки

В `CorrelationAnalysisService`:

```python
self.min_sample_size = 10  # Минимум наблюдений
self.min_confidence = 0.95  # 95% уверенность
self.min_correlation = 0.6  # Минимальный коэффициент корреляции
```

Можно изменить для более/менее строгого анализа.

## Примечания

- Система НЕ заменяет медицинские консультации
- Факты основаны на персональных данных пользователя
- Научные объяснения генерируются AI и могут быть неточными
- Рекомендуется собрать 20+ наблюдений для надёжных выводов
