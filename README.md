# NutriAI Bot

**Telegram-бот с искусственным интеллектом для персонализированного планирования рациона питания**

NutriAI использует Claude API для интеллектуального анализа питания, распознавания еды по фото и предоставления персонализированных рекомендаций.

## Возможности

- ✅ **Распознавание еды по фото** - просто отправь фото блюда, и бот автоматически определит калории и БЖУ
- ✅ **Персонализированный профиль** - расчет целевых калорий и макронутриентов на основе твоих параметров
- ✅ **AI-чат с нутрициологом** - задавай вопросы о питании и получай научно обоснованные ответы
- ✅ **Дневник питания** - отслеживание всех приемов пищи (в разработке)
- ✅ **Аналитика и статистика** - графики, инсайты и рекомендации (в разработке)

## Технологический стек

- **Backend**: FastAPI, SQLAlchemy (SQLite)
- **Bot**: python-telegram-bot
- **AI**: Anthropic Claude API
- **Database**: SQLite (для простоты развертывания)

## Требования

- Python 3.11+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- Anthropic API Key (зарегистрироваться на [anthropic.com](https://console.anthropic.com/))

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/nutriai-bot.git
cd nutriai-bot
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации

Скопируйте `.env.example` в `.env` и заполните необходимые данные:

```bash
cp .env.example .env
```

Откройте `.env` и укажите:

```env
# Telegram Bot Token (получить у @BotFather)
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here

# Anthropic Claude API Key
ANTHROPIC_API_KEY=your_anthropic_api_key_here

# Секретный ключ (сгенерируйте случайную строку)
SECRET_KEY=your-random-secret-key-change-this
```

### 5. Инициализация базы данных

База данных SQLite создастся автоматически при первом запуске. Файл БД: `nutriai.db`

**Применение миграций:**

После первого запуска бота (когда файл `nutriai.db` создан), необходимо применить миграции базы данных:

```bash
python apply_migrations.py
```

Это добавит необходимые поля и таблицы в базу данных. Миграции применяются автоматически, скрипт отслеживает какие миграции уже были применены.

Вы должны увидеть:
```
============================================================
NutriAI Database Migration Tool
============================================================
Found X migration files
✓ migration_name.sql - applied successfully
...
============================================================
Migration completed successfully!
============================================================
```

**Важно:** Применяйте миграции каждый раз после обновления кода, если появились новые файлы в папке `migrations/`.

### 6. Запуск бота

#### Быстрый запуск (рекомендуется)

**Для Linux/Mac:**
```bash
./start.sh
```

**Для Windows:**
```batch
start.bat
```

Скрипт автоматически:
- Проверит и запустит Redis и PostgreSQL
- Запустит Celery Worker (для фоновых задач)
- Запустит Celery Beat (для периодических задач)
- Запустит бота

Логи будут доступны в директории `logs/`:
- `logs/bot.log` - основной лог бота
- `logs/celery_worker.log` - лог Celery Worker
- `logs/celery_beat.log` - лог Celery Beat

#### Остановка бота

**Для Linux/Mac:**
```bash
./stop.sh
```

**Для Windows:**
Закройте все открытые окна с процессами или нажмите Ctrl+C в каждом.

#### Ручной запуск

Если хотите запустить компоненты вручную:

**Терминал 1 - Celery Worker:**
```bash
cd /home/user/tricer
celery -A app.celery_app worker --loglevel=info
```

**Терминал 2 - Celery Beat:**
```bash
cd /home/user/tricer
python celery_beat.py
```

**Терминал 3 - Bot:**
```bash
python -m app.bot.main
```

Вы должны увидеть:
```
Starting NutriAI Bot...
Bot started successfully!
```

### 7. (Опционально) Запуск FastAPI сервера

В отдельном терминале запустите API сервер:

```bash
python -m app.main
```

API будет доступен по адресу: `http://localhost:8000`

Документация API (Swagger): `http://localhost:8000/docs`

## Получение API ключей

### Telegram Bot Token

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Сохраните полученный токен

### Anthropic Claude API Key

1. Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com/)
2. Перейдите в раздел API Keys
3. Создайте новый ключ
4. Сохраните ключ (он показывается только один раз!)
5. Пополните баланс для использования API

**Стоимость Claude API:**
- Input: ~$3 / 1M tokens
- Output: ~$15 / 1M tokens
- Распознавание одного фото: ~$0.01-0.03

## Часто задаваемые вопросы

**Q: Почему используется SQLite вместо PostgreSQL?**
A: Для простоты развертывания на любых серверах без необходимости настройки СУБД. Для production рекомендуется PostgreSQL.

**Q: Сколько стоит запустить бота?**
A: Основные расходы - Claude API (~$0.01-0.03 за распознавание фото). Для 100 пользователей в день: ~$30-50/месяц.

**Q: Можно ли использовать бесплатно?**
A: Да, бот open-source. Anthropic предоставляет $5 бесплатных кредитов для тестирования.

**Q: Как точно распознается еда?**
A: Claude имеет точность ~85-90% для популярных блюд. Сложные или необычные блюда могут распознаваться хуже.
