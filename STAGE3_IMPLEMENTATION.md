# Этап 3: Продвинутые функции - Реализация

## Обзор
Этап 3 добавляет продвинутые функции мониторинга микронутриентов (витамины и минералы) и генерацию PDF-отчетов с графиками.

## Реализованные функции

### 1. Учет микроэлементов и витаминов

#### Список отслеживаемых микронутриентов:

**Витамины:**
- Витамин A (мкг)

- Витамин C (мг)
- Витамин D (мкг)
- Витамин E (мг)

**Минералы:**
- Кальций (Ca) - мг
- Фосфор (P) - мг
- Магний (Mg) - мг

- Натрий (Na) - мг

- Железо (Fe) - мг
- Цинк (Zn) - мг
- Йод (I) - мкг
- Селен (Se) - мкг

#### Целевые значения (РСП):
Реализован справочник `MicronutrientTargets` с рекомендуемыми суточными нормами для взрослых мужчин и женщин на основе МР 2.3.1.0253-21 (Нормы физиологических потребностей РФ).

### 2. Модели данных

#### `DailyMicronutrients`
Таблица для хранения агрегированных данных по микронутриентам за день:
```sql
CREATE TABLE daily_micronutrients (
    id INTEGER PRIMARY KEY,
    user_id INTEGER,
    date DATE,
    vitamin_a REAL,
    beta_carotene REAL,
    ... (все микронутриенты)
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);
```

#### Расширение существующих моделей:
- `meal_foods.micronutrients` (JSON) - микронутриенты конкретного блюда
- `planned_meals.micronutrients` (JSON) - планируемые микронутриенты

---

### 3. Сервисы

#### `MicronutrientService`
Функции:
- `update_daily_micronutrients()` - обновление суточных данных
- `get_daily_micronutrients()` - получение данных за день
- `get_period_micronutrients()` - данные за период
- `calculate_period_average()` - средние значения за период
- `get_micronutrient_targets()` - целевые значения для пользователя
- `recalculate_daily_totals()` - пересчет при редактировании

#### `NutritionReportService`
Функции:
- `get_daily_report()` - отчет за день
- `get_period_report()` - отчет за неделю/месяц
- `get_plan_comparison()` - сравнение плана и факта

Отчеты включают:
- Макронутриенты (КБЖУ) с процентами выполнения
- Микронутриенты с процентами от РСП
- Разбивку по дням (для периодов)
- Средние и суммарные значения

---

### 4. PDF-отчеты с графиками

#### `PDFReportGenerator`
Генерирует красивые PDF-отчеты с:

**Графики:**
1. **Круговая диаграмма КБЖУ** - показывает распределение калорий между белками, жирами и углеводами
2. **Прогресс-бары (ползунки)** - для визуализации % выполнения по калориям, белкам, жирам, углеводам

**Таблицы:**
1. **Макронутриенты** - факт, цель, процент
2. **Витамины** - до 10 основных витаминов
3. **Минералы** - до 12 основных минералов

**Дисклеймер:**
В каждом отчете присутствует важное примечание:
```
⚠️ Данные о микронутриентах являются примерной оценкой
и могут отличаться от фактических значений.
```

#### Периоды отчетов:
- **День** - данные за текущий день
- **Неделя** - последние 7 дней с усреднением
- **Месяц** - последние 30 дней с усреднением

## Важные примечания

### ⚠️ Дисклеймер о микронутриентах

Бот **обязательно** уведомляет пользователей:
- Данные являются **примерной оценкой**
- Расчеты основаны на усредненных данных
- Для точной оценки рекомендуется консультация специалиста

Дисклеймер появляется:
- В PDF-отчетах (на каждой странице)
- При запросе отчета через бота
- В разделе с микронутриентами

### Рацион на месяц

Система учитывает, что полноценный рацион по всем микронутриентам формируется за **месяц**, а не за день:
- Отчеты за месяц показывают средние значения
- Нормально, если не все микронутриенты достигают 100% за день
- Важен баланс за длительный период
