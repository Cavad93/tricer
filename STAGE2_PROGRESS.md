## ✅ 2. Функция "Ресторан"

### Реализовано:
Полнофункциональная система анализа меню ресторана с AI и подбором блюд по текущему рациону.

### Workflow:
1. **Вход**: Пользователь нажимает "🍴 Ресторан" в главном меню
2. **Отправка фото**: Пользователь фотографирует меню ресторана
3. **Уточнение настроения**:
   - 🍰 Хочется сладкого
   - 🥩 Хочется сытного/жирного
   - 🥗 Хочется легкого/растительного
   - 🌶 Хочется острого
   - 🧘 Не важно, главное здоровое
4. **Уточнение приема пищи**: Завтрак / Обед / Ужин / Перекус
5. **AI-анализ**: Claude Vision анализирует меню с учетом:
   - Текущего прогресса по калориям и БЖУ
   - Оставшихся калорий на день
   - Настроения пользователя
   - Типа диеты и аллергий
   - Активного плана питания
6. **Рекомендации**: 2-3 блюда с КБЖУ и объяснением выбора

### Файлы:
- `app/bot/handlers/restaurant.py` - новый полный handler
- `app/bot/states.py` - RestaurantStates (ASKING_MOOD, ASKING_MEAL_TIME, ANALYZING_MENU)
- `app/bot/keyboards.py` - добавлена кнопка "🍴 Ресторан"
- `app/bot/main.py` - restaurant_conversation ConversationHandler

### Технологии:
- Claude Vision API для распознавания меню
- Интеграция с MealService для получения прогресса
- Умный AI prompt учитывающий все параметры пользователя

## ✅ 4. Психотерапевтический подход при отклонениях

### Реализовано:
Эмпатичная система реагирования на отклонения от плана питания без осуждения.

### Детекция отклонений:
1. **Превышение дневной нормы калорий**:
   - Расчет перевыполнения
   - Поддерживающее сообщение с использованием FriendlyPhrases
   - Предложение помощи в корректировке оставшихся приемов пищи

2. **Отклонение от запланированного (>30% по калориям)**:
   - Сравнение добавленного блюда с запланированным
   - Мягкое признание отклонения
   - Фраза: "Это абсолютно нормально! Жизнь непредсказуема"
   - Фокус на оставшихся калориях как на возможности

3. **Все идет по плану**:
   - Поощрение через FriendlyPhrases
   - Мотивация продолжать

### Принципы:
- **Без осуждения**: никогда не используется слово "срыв" или "неправильно"
- **Эмпатия**: понимание что жизнь непредсказуема
- **Конструктив**: фокус на решении, а не на проблеме
- **Мотивация**: один промах не отменяет прогресс
- **Поддержка**: предложение конкретной помощи

### Файлы:
- `app/bot/handlers/photo.py` - детекция отклонений при добавлении еды
- `app/bot/texts.py` - FriendlyPhrases для поддержки

## ✅ 5. Автоматическая коррекция рациона

### Реализовано:
AI-чат может помогать пользователям корректировать оставшиеся приемы пищи на день с учетом уже потребленного.

### Расширенный контекст для AI:
Теперь AI-чат получает полную информацию:
- **Потреблено сегодня**: калории, белки, жиры, углеводы
- **Осталось на сегодня**: калории, белки, жиры, углеводы
- **Активный план**: наличие плана и запланированные блюда
- **Профиль пользователя**: цели, диета, аллергии

### Функциональность AI:
При обращении пользователя за помощью в корректировке рациона, AI:
1. **Использует психотерапевтический подход**:
   - Выслушивает без осуждения
   - Спрашивает о причинах (если уместно)
   - Подбадривает

2. **Предлагает конкретные решения**:
   - 2-3 варианта блюд для оставшихся приемов пищи
   - С точным КБЖУ
   - Укладываются в оставшиеся калории
   - Соответствуют диете пользователя
   - Учитывают аллергии
   - Помогают достичь баланса макронутриентов

3. **Мотивирует**:
   - Напоминает что один промах не отменяет прогресс
   - Фокусируется на следующих шагах

### Техническая реализация:
- Расширен `ChatService.get_user_context()`:
  - `remaining_calories/proteins/fats/carbs` - оставшиеся макросы
  - `has_active_plan` - флаг наличия плана
  - `today_plan_summary` - краткое описание запланированных блюд

- Обновлен system prompt в `claude_ai.py`:
  - Секция "СПЕЦИАЛЬНАЯ ФУНКЦИЯ - КОРРЕКЦИЯ РАЦИОНА"
  - Детальные инструкции по психотерапевтическому подходу
  - Требования к предлагаемым блюдам
  - Формат ответа с КБЖУ

### Файлы:
- `app/services/chat_service.py` - расширен user_context
- `app/services/claude_ai.py` - обновлен system prompt для чата

### Примеры использования:
1. Пользователь превысил норму на обед → бот предлагает обратиться в AI-чат
2. В AI-чате пользователь пишет: "Помоги скорректировать ужин"
3. AI предлагает легкие варианты ужина с КБЖУ, которые вписываются в оставшиеся калории
4. Пользователь выбирает вариант и готовит
